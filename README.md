# 数学二知识树与历年真题

高等数学15讲、线性代数6章；295个知识点；1987–2024年38年、825道真题。

https://mofan6.github.io/math2-knowledge-tree/

点击知识点，在大窗口查看本节点及下级节点的相关真题。综合题关联多个知识点，列表去重，按相对难度由易到难排列。同级按年份和原题号排列。

支持深色模式、年份与题型筛选、查看原卷整页、打开该年解析、直接下载当前知识点的题目PDF，以及浏览器打印。

## 题号与核对

早年试卷按“原卷大题号（小题号）”标注；解答题内的各分问作为一个原题整体收录。2000年含十三题，2007年含第24题。归类核对表见 [question-index.csv](question-index.csv)。难度和知识点归类为整理时的判断。

## 资料来源与使用

- 高等数学知识结构参考《张宇基础30讲（高数）》，保留数学二适用部分及90条原蓝字细节。
- 线性代数知识结构参考《线性代数基础讲义》（没咋了），排除标为“仅数一”的向量空间部分。
- 真题及解析来自网站维护者提供的1987–2024年数学二资料；原资料中的署名、出处及权利信息以相应文件为准。
- 网站维护者已确认具有本次公开发布所需的相关网络传播授权。资料权利归相应权利人；本仓库公开不代表向访问者授予资料的再次传播或其他使用许可。

## 部署

这是无后端的静态网站。GitHub Pages 的发布源为 `main` 分支根目录，并由 `.nojekyll` 跳过Jekyll处理。

题干、原卷页和解析按需加载。PDF在访问者浏览器中生成；网站代码未添加统计脚本、第三方CDN、账号登录或向服务器提交答题数据的功能。
